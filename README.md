# Lab 01 - Packet Tracer Introduction

## Overview

In my first lesson, following Jeremy's IT Lab course, I built a virtual network lab in Cisco Packet Tracer to simulate a WAN connecting two branches: New York and Tokyo.

The topology represents an enterprise network with two separate LANs connected through the Internet.

Each branch contains:
- Switches connecting multiple devices within the LAN.
- A router acting as the gateway for the LAN.
- A firewall protecting the internal network.
- End devices such as PCs and servers.

The two branches communicate through the Internet, represented by the routers and network path between them.

The topology also includes an external attacker to represent a potential threat coming from outside the network. The firewalls are positioned between the internal networks and the Internet to provide a security boundary.

## What I Did

- Built the network topology in Cisco Packet Tracer.
- Created two simulated branches: New York and Tokyo.
- Added routers, switches, firewalls, PCs, and servers.
- Connected the devices to represent a WAN environment.
- Added an external attacker to represent a potential security threat.

## What I Learned

- How to build a network topology in Cisco Packet Tracer.
- The role of switches in a LAN.
- The role of a router as a gateway.
- How WANs can connect different networks.
- The role of firewalls in protecting internal networks.
- How an external attacker can be represented in a network topology.
